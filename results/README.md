# Experimental Results & Figures

This directory stores the raw execution logs and all 54 experimental visualizations generated by `notebooks/covid19_xray_adversarial_robustness.ipynb` and published in the JEEEMI article.

## Directory Contents

- [`full_hasil.txt`](full_hasil.txt) — Complete console output log from the CUDA GPU evaluation run, including dataset verification, per-class `classification_report` tables, sub-pixel sensitivity DataFrames, and final report summaries.
- [`figures/`](figures/) — Physical directory containing all **54 PNG figures**, including:
  - System architecture & pipeline diagrams (`architecture_diagram.png`, `cropped_architecture_diagram.png`, `fig3_ilustrasi_fgsm.png`, `fig4_ilustrasi_pgd.png`)
  - Dataset sample distributions (`fig2_dataset_representative_samples_stats.png`, `sample_dataset.png`)
  - Training convergence curves (`training_validation_acc_loss_densenet121.png`)
  - Confusion matrices (`cm_original_test_set.png`, `cm_fgsm_test_set.png`, `cm_pgd_test_set.png`, `cm_fgsm_vs_pgd_0.1.png`, `fig7_cm_fgsm_detailed_percentage.png`, `fig8_cm_pgd_detailed_percentage.png`)
  - Sub-pixel robustness profiles (`robustness_profile_degradasi_akurasi_pada_noise_sub_pixel_dan_mikro.png`, `analisis_batas_toleransi_fgsm.png`, `analisis_batas_toleransi_pgd.png`, `model_sensitivity_pgd_0.01-0.3_255.png`, `head-to-head-fgsm-pgd.png`)
  - Grad-CAM & noise progression grids (`Visualisasi_Grad-CAM_(Clean_vs_FGSM_vs_PGD).png`, `analisis_progresi_pgd_kelas_*.png`, `analisis_progresi_fgsm_(auto-enhanced-noise)_kelas_*.png`, `analisis_sub_pixel_*`, `visualisasi_5_sampel_kelas_*`)
